# Fadoua Mahroug — Portfolio

A professional, editorial-style portfolio built with Next.js.

## Add your photos

Place these four files inside `public/`:

- `image1.jpg` — GastroNeXia
- `image2.jpg` — SAWTNA / Code4Palestine
- `image3.jpg` — Agri Challenge
- `image4.jpg` — Scratch Programming Instructor

The other projects intentionally use typography/graphic placeholders rather than stock images.

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000
